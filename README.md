# LexMemoria · corpus BOE

12451 normas del catálogo consolidado observado el 05/11/2026. Paquetes estructurados con texto e historial de bloques, atribución, fuente y SHA-256. No es cobertura universal ni revisión editorial.

Fuente y condiciones: https://www.boe.es/informacion/aviso_legal/index.php#reutilizacion

El catálogo incorporado en la app permite preparar 684375 tarjetas base de recuerdo literal. Los formatos de huecos, test literal y reconocimiento de artículos se derivan de fragmentos con fuente, sin inferir interpretación jurídica.

Auditoría completa para LexMemoria 0.4.0, formatos v2: 8.386.362 ejercicios derivados (684.375 de recuerdo, 2.747.278 de huecos, 2.827.050 test literales y 2.127.659 de reconocimiento de artículos). Huecos y test utilizan pasajes de hasta 320 caracteres Unicode; los huecos incluyen dos o tres respuestas distintas. El formato de recuerdo mantiene sus identificadores anteriores. Los paquetes fuente y el catálogo conservan su contenido y hash. No se descargan todas las tarjetas al instalar la app: se preparan por norma y formato.

`verification.json` coteja 12.451 paquetes y 695.207 versiones de bloques con el archivo oficial retenido. `exercises-verification.json` comprueba citas, respuestas, ausencia de alternativas ambiguas y cobertura completa del catálogo; incluye el SHA-256 del índice. La revisión técnica no es revisión jurídica humana.
