# LexMemoria — biblioteca europea completa

184,737 registros agrupados en 149,352 actos, con todas sus ediciones y 280,961 referencias de archivos originales.

Inventario observado: sectores CELEX 0 y 3 con expresión española. Las bases de las 28.905 consolidaciones se contrastan con la relación oficial CDM; los tratados y acuerdos conservan su identificador y familia.

Fuente: Oficina de Publicaciones de la Unión Europea. Extracción automática, sin revisión jurídica manual. Las fichas sin texto recuperable conservan su fuente oficial.

Cada objeto declara SHA-256 de bytes comprimidos, tamaño comprimido y expandido; páginas JSONL. El índice se publica después de todos sus objetos.
