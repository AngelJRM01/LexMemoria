Estudio local

Puedes estudiar sin crear una cuenta. El móvil conserva perfil, tarjetas, notas, planificación, respuestas, historial y posiciones de lectura. Android usa SQLCipher y una clave separada en Keystore. No se garantiza la conservación si borras datos, desinstalas o pierdes el dispositivo. Puedes exportar una copia JSON: es legible y debes custodiarla. La edición web tiene almacenamiento distinto y no se anuncia como esta aplicación Android.

Cuenta y sincronización opcionales

Si eliges Google, Firebase Authentication procesa la identidad de acceso. La API valida esa identidad y asocia tus datos a la cuenta. Al sincronizar se transmiten los datos admitidos: tarjetas, revisiones, estados, eventos de repaso, perfil/preferencias, notas, cursos, plan, marcadores, lectura y simulacros. La sincronización automática requiere consentimiento separado y opera mientras la aplicación está abierta; entrar con Google no prueba que todos los datos estén sincronizados.

La API y la base PostgreSQL se alojan en Render. La aplicación usa HTTPS para datos remotos y controles de propietario. SQLCipher local no significa cifrado de extremo a extremo de la base remota: el servicio puede procesar los datos para prestar la función. No introduzcas información de terceros o especialmente sensible en apuntes o tarjetas.

Colaboración privada

Si la utilizas, se procesan alias, perfil y los materiales que elijas compartir, invitaciones, roles y relaciones de acceso. Notas, calificaciones y progreso no se publican automáticamente. Puedes retirar acceso, bloquear y denunciar. Una copia legítimamente recibida antes de retirar acceso puede permanecer en el dispositivo del destinatario. La publicación y el catálogo público de mazos están desactivados para esta edición.

Foto opcional

Puedes elegir un avatar o foto. La importación de foto Google requiere una acción/consentimiento específico. La imagen pasa validaciones técnicas y retirada de EXIF; no hay un servicio de reconocimiento facial. No subas imágenes de terceros sin autorización.

Fuentes públicas y servicios externos

Los paquetes jurídicos públicos se descargan desde la distribución pública en GitHub. Los proveedores de red reciben los datos técnicos necesarios para servir las peticiones, como la dirección IP. Al abrir BOE/EUR-Lex u otros enlaces se aplican las condiciones de esos sitios. La lectura en voz usa el servicio TTS del dispositivo y su configuración, que puede tener condiciones de procesamiento propias.

Firebase/Google, Render y GitHub intervienen según las funciones utilizadas. Región comunicada de API/base: Frankfurt; debe verificarse en el despliegue definitivo. El titular debe revisar contratos, subencargados y transferencias internacionales aplicables. No se afirma que toda operación de todos los proveedores esté limitada a esa región.

No hay publicidad ni proveedor de analítica de uso conectado en la aplicación. No se envían notas o respuestas a proveedores de IA. La edición 1.0 no incorpora compras activas. Los registros técnicos necesarios para seguridad/operación se deben describir según la configuración real del despliegue.

Conservación y copias

Los datos locales permanecen hasta que los elimines o se retire el almacenamiento de la app. Los datos remotos se conservan mientras la cuenta esté activa según la política aprobada. El borrado retira los datos de la cuenta de los sistemas activos y puede anonimizar atribuciones de copias ya compartidas. Las copias operativas requieren un plazo definido: [PLAZO REAL DE BACKUPS/LOGS Y PROCEDIMIENTO DE EXPIRACIÓN]. No se promete un plazo de borrado de backups que aún no esté implantado.

El alias retirado tiene una reserva técnica de 30 días para impedir suplantaciones; se debe reflejar su tratamiento en la política final. La definición de conservación de reportes/auditoría y obligaciones legales corresponde al titular y debe coincidir con la operación.

Exportación y eliminación

Desde Perfil → Cuenta y copias se ofrecen exportación y eliminación remota con confirmación e identidad reciente. Eliminar datos locales es una acción distinta. La eliminación asociada a Google debe completar también el paso del proveedor; la app conserva un reintento si falla esa coordinación. No se presenta como aceptado hasta probarlo con una cuenta real.

Vía web prevista: https://lexmemoria-api.onrender.com/account/delete. Debe configurarse y probarse el acceso Firebase web y el dominio autorizado. No basta con que cargue la página. Canal alternativo de derechos: [CORREO PÚBLICO DEL RESPONSABLE].
